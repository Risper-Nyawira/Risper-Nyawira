## Featured projects

### 🌾 Food-Producing Communities and Food Security in Kenya
**Research question:** Why can food-producing communities still experience food insecurity?

Explores maize production, yield, cultivated area, prices, climate indicators, and food-insecurity measures to examine why production alone does not guarantee food access. The project emphasises affordability, market access, and careful interpretation of a small dataset.

**Tools:** SQL/SQLite, Python, pandas, Matplotlib, Power BI  
[Explore the repository →](https://github.com/Risper-Nyawira/food-producing-communities-food-security)

### 📈 Kenya Agricultural Market Intelligence
A developing tomato-market pilot examining price patterns, seasonality, market differences, and the quality and coverage of available data. The documentation distinguishes observed associations from causal claims and identifies where more geographically detailed data is needed.

**Focus:** Agricultural value chains, market intelligence, data auditing, and decision support  
[Explore the repository →](https://github.com/Risper-Nyawira/kenya-agricultural-market-intelligence.)

### 🌍 Kenya Food Security Analysis
A structured workspace for examining the relationships between agricultural production, climate variability, market dynamics, and food security, with documented data preparation and analysis stages.

**Workflow:** SQL/SQLite, processed datasets, Python notebooks, and planned dashboard outputs  
[Explore the repository →](https://github.com/Risper-Nyawira/kenya-food-security-analysis)

## How I work

- Start with a clear, decision-relevant research question.
- Document data sources, definitions, cleaning decisions, and limitations.
- Build transparent, reproducible workflows where practical.
- Distinguish descriptive patterns and correlations from causal conclusions.
- Communicate findings in a way that supports practical decisions.
